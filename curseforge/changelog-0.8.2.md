## 0.8.2 — Edit a point in the world

**New**

- **Right-click a point in the world.** With the trigger item in your main hand (rails by default) and the crosshair on a point's vertical pin, a right-click opens the same Y / name / kind box you get by double-clicking a vertex in the map — no need to open the map to fix one elevation.
- The point you are aiming at gets a **white box** first, so you see what you are about to edit; look away and the right-click is an ordinary right-click again.
- Both halves are configurable on the settings page: a switch to turn the whole thing off, and a field for the **trigger item** (any item id, `minecraft:rail` by default).

**Unchanged**

- Save format and sync protocol are the same as 0.8.1 (protocol 3), so a 0.8.1 server and this client still talk to each other.
- Nothing in the map changed: double-clicking a vertex still opens the same box, and the keys, the maths and the world rendering are untouched.

## 0.8.2 —— 在世界里直接改点位

**新增**

- **拿着物品右键点世界里的点位。** 主手拿触发物品（默认铁轨），准星对准点位那根竖针，右键弹出和地图里双击顶点完全一样的框（Y / 名字 / 类型）——为了改一个标高不用再开地图。
- 准星先给命中的那个点套一个**白框**，右键之前就知道改的是哪一个；移开准星，右键又变回普通右键。
- 两半都能配：设置页左栏有一个总开关，还有一个**触发物品**输入框（任意物品 id，默认 `minecraft:rail`）。

**不变**

- 存档格式与同步协议和 0.8.1 一样（协议 3），0.8.1 的服务端与这个客户端照样互通。
- 地图里一点没变：双击顶点还是那个框，键位、几何、世界渲染都没动。
